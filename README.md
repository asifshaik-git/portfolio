- Responsive web experience

## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/asifshaik-git/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the local URL displayed in your terminal.
